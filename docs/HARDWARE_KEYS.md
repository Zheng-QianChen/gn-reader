# 实体键映射与触控屏蔽

GN Reader **v0.1.30+** 支持把手机上的实体键（音量、侧键、相机键等）映射为阅读操作，并用短时连按开关触控屏蔽（口袋防误触）。

## 默认行为

| 按键 | 默认动作 |
|------|----------|
| 音量 + | 上一页 |
| 音量 - | 下一页 |
| 音量 - 连按 3 次（约 0.9s 内） | 开启 / 解除触控屏蔽 |

可映射动作：上一页 / 下一页 / 上一章 / 下一章 / 菜单显隐 / 朗读开关 / 触控屏蔽开关 / 无。

## 设置入口

阅读页 → 设置 → **实体键 / 触控屏蔽**

1. **按下实体键以添加/编辑映射**：进入监听后按下手机任意实体键（系统会把能传到 App 的键交给阅读器，含额外侧键）。
2. 在列表中点按某键，选择功能。
3. **触控屏蔽 · 短时连按开关**：可改绑手势键、连按次数（2～8）、判定窗口（300～3000ms）。

TXT 阅读页顶栏有 **按键** 按钮，打开同一套设置。

## 触控屏蔽

- 开启后阅读区域忽略手指触摸，顶部提示「触控已屏蔽」。
- 仍可用实体键翻页 / 连按解除。
- 打开设置页时临时允许触摸，便于改映射。

### 连按手势细则

对手势键：

1. **第 1 次**：立即执行该键已映射的动作（如翻页）。
2. **窗口内第 2～N-1 次**：只计数，不再翻页。
3. **达到 N 次**：切换触控屏蔽。

也可把某个侧键单独映射为「触控屏蔽开/关」，一键切换。

## 技术说明

- `MainActivity.dispatchKeyEvent` 统一拦截，避免 WebView 抢走音量键。
- 映射存于 `AppSettings.keyMappingsJson`（keyCode → action id）。
- 未映射且非手势键的按键不拦截，交给系统。
- 返回键不参与映射。

## 限制

- 部分厂商侧键若只触发系统级快捷方式、不向 App 派发 `KeyEvent`，则无法绑定；设置页「最近检测到」可确认该键是否可达。
- 耳机线控 / 媒体键视机型与系统而定。
