# Fonts for gn-reader

Bundled (free / open licenses — app is non-commercial):

- **LXGW WenKai Lite** (`LXGWWenKaiLite-Regular.ttf`) — Chinese kai style, SIL OFL 1.1 (see OFL-LXGW-WenKai.txt).
- **Smiley Sans** (`SmileySans-Oblique.ttf`) — 得意黑, SIL OFL 1.1 (see OFL-SmileySans.txt).
- **Liberation Serif** (`LiberationSerif-Regular.ttf`) — Times-compatible metrics (see LIBERATION_LICENSE.txt).

Downloaded on first use:

- **Noto Serif SC** — Song / 公文新宋 style (OFL). Stored under app filesDir.

See `fonts.json` for the catalog.
